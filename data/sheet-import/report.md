## 7. 시트 ↔ DB 매핑

`server/src` 기준 `items` 테이블 컬럼은 다음뿐이다 (v2.5에서 `category_id` 제거).

| 시트 | `items` | 처리 |
|---|---|---|
| 상품 이름 | `name` | 그대로 |
| 사이즈/규격 + 비고 | `description` | 합쳐서 1개 텍스트 |
| 상태 (사용가능/고장) | `status` | `active` / `repair` (+ 이관·배부 완료 시 `retired`) |
| 갯수 | `total_qty` | 정수 파싱. 위 3.1 미확정건 제외 |
| — | `max_days` | 시트에 없음 → 정책값 7 |
| 분류 | (없음) | 앱에는 카테고리 없음 — 물리 정리용으로만 유지 |
| 위치 | (없음) | 보관 장소를 앱에 노출하려면 별도 필드 필요 (v2 후보) |
| 향후 처리방안 | `status` 보조 | 배부/이관 확정 건은 대여 목록에서 제외 |

# 01 — 제품 규칙

이 서비스가 무엇을 허용하고 무엇을 금지하는가의 단일 출처다. 제품 규칙은 이 문서에서
시작해 [02 가입과 로그인](02-signup-and-login.md), [03 화면과 경로](03-screens-and-routes.md),
[04 회원 관리](04-member-management.md), [05 대여 불변식](05-rental-invariants.md)으로 이어진다.
구현 구조는 [06 시스템 개요](06-system-overview.md), UI 기준은 [10 디자인 시스템](10-design-system.md)을 본다.

## 역할과 권한

| 역할 | 정의 | 할 수 있는 것 |
| --- | --- | --- |
| 방문자 | 세션 없음 | 로그인, 정책 열람 |
| 회원 (`user`) | 구글 로그인 + 프로필(이름·연락처) 등록 | 물품 목록·상세·검색·사진, 대여 신청·예약·취소·반납(상태 사진 첨부), 내 대여 현황, 프로필 편집 |
| 관리자 (`admin`) | `members.role = 'admin'` | 회원의 모든 것 + 물품 등록·수정·사진, 대여 신청·예약 승인·거절, 반납 처리(상태 사진 첨부), 회원 탈퇴·역할 지정, 등록 정보 삭제, 로그인 허용 관리 |

- 새로 가입한 회원의 기본 역할은 **`user`**다. 가입만으로 관리자가 되지 않는다.
  관리자 지정은 기존 관리자가 회원 관리 화면에서 역할을 바꾸거나, DB에서 직접 한다
  ([16 데이터베이스 운영](16-database-operations.md)).
- 마지막 남은 관리자는 해임·탈퇴시킬 수 없다. 서버가 거부한다.

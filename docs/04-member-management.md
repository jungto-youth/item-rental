# 04 — 회원 관리

탈퇴·등록 정보 삭제·역할 변경·허용 목록 관리처럼 회원 상태를 바꾸는 정책.

## 회원 관리 정책

- **탈퇴**는 계정을 비활성화하고 이력을 남긴다. 탈퇴 회원이 다시 로그인하면 같은 계정이
  복구되지만 역할은 일반 회원으로 초기화된다. 대여·관리 이력은 유지된다.
- 탈퇴·등록 정보 삭제 시 아직 시작되지 않은 **승인 대기(`pending`)·예약(`reserved`)** 건은
  자동으로 취소된다. 대여 중(`rented`)인 물품이 있으면 탈퇴는 허용되지만(소프트 삭제),
  등록 정보 삭제는 거부된다.
- **등록 정보 삭제**는 대여 중인 물품이 없을 때만 가능하다. 이름·이메일·연락처를 제거하고
  내부 ID와 완료된 대여·관리 이력은 익명으로 보존한다.
- 등록 정보를 삭제한 이메일로 다시 로그인하면 새 `user` 회원으로 등록된다.
- **차단 기능은 없다.** 탈퇴·등록 정보 삭제는 접근을 막는 수단이 아니다 — 정토회 계정
  (`@jungto.org`)은 다시 로그인하면 복구되거나 새로 가입된다. 예외 계정은 허용 목록에서
  지우면 남은 세션까지 막힌다. 정토회 계정을 막아야 하는 경우가 생기면 이메일 기준 차단
  목록을 별도로 둔다(회원 행에 표시하면 등록 정보 삭제 때 이메일과 함께 사라진다).
- 마지막 활성 관리자는 탈퇴시키거나 역할을 내릴 수 없다.

# 02 — 가입과 로그인

누가 로그인할 수 있는지, 최초 로그인 뒤 무엇을 등록해야 하는지, 거부 사유를 어떻게 구분하는지.

## 가입과 로그인

- **로그인이 곧 가입이다.** 구글 계정으로 처음 로그인하면 회원 행이 생기고, 이름·연락처를
  입력하면 바로 이용한다. 별도 회원가입 화면이나 승인 대기는 없다.
- 로그인 가능 계정은 다음뿐이다.
  - 정토회 계정: 이메일이 `@jungto.org`로 끝나는 계정
  - 관리자가 등록한 예외 이메일: DB `allowed_emails` 테이블 (정식 경로)
  - 비상용 환경 변수 `AUTH_ALLOWED_EMAILS` (콤마 구분, DB 조회 실패 시 폴백)
- 구글 프로필의 `email_verified`가 `true`인 경우만 통과한다.
- 거부·실패는 로그인 화면으로 돌아오며 `?error=` 값으로 구분한다.
  - `denied` — 정토회 계정도 예외 목록도 아님
  - `deactivated` — 등록 정보가 삭제된 회원
  - `unavailable` — 세션 발급 실패
- 프로필의 이름·연락처·지부·지회·모둠은 **모두 필수**다. 지부는 청년지부·대중지부 중
  하나다. 청년지부는 지회(서울·경기·남부)와 모둠을 목록에서 고르고, 대중지부는
  지회·모둠을 직접 입력한다. 대여 신청 시점의 소속은 예약에 스냅샷으로 남는다.
- 지부·지회·모둠이 없는 회원은 **역할과 무관하게**(관리자 포함) 로그인 후
  `/signup/profile`에서 이름·연락처·지부·지회·모둠을 등록해야 다른 화면을 이용할 수 있다.
- 허용되지 않는 계정에는 "정토회 계정 또는 관리자가 허용한 계정만 로그인할 수 있다"는
  안내가 로그인 화면 **앞쪽**에 보여야 한다. (→ [17 백로그](17-backlog.md) B-03)

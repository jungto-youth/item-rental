# 03 — 화면과 경로

화면 목록, 경로, 접근 권한, 관리자와 회원이 화면을 오가는 규칙.

## 화면과 경로

| 경로 | 화면 | 접근 |
| --- | --- | --- |
| `/` | 물품 현황 — 검색·상태 필터·스크롤 자동 불러오기·관리자 모드 | 로그인 |
| `/items/:id` | 물품 상세 — 갤러리·수량 스테퍼·대여 | 로그인 |
| `/items/new` | 물품 등록 — 검증·태그·사진 | 관리자 |
| `/items/:id/edit` | 물품 수정 — 삭제 | 관리자 |
| `/login` | 구글 로그인 · 로컬 테스트 로그인 | 공개 |
| `/signup/profile` | 최초 로그인 후 이름·연락처·지회·모둠 등록 | 로그인 |
| `/mypage` | 내 정보 — 표시/수정, 필수 정보 미등록 배너 | 로그인 |
| `/my/rentals` | 대여 내역 — 승인 대기·예약 대기·거절·반납 예정일·기한 지남·반납·취소·이력·반납 사진 | 로그인 |
| `/admin/reservations` | 대여 관리 — 신청·예약 승인·거절·상태·기한 지남 필터·반납 처리·반납 사진 | 관리자 |
| `/admin/members` | 회원 관리 — 역할·탈퇴·정보 삭제·허용 이메일 | 관리자 |
| `/policy/:kind` | 이용약관 · 개인정보 처리방침 | 공개 |
| 그 외 | 404 | 공개 |

- 로그인·프로필 등록은 헤더·푸터가 없는 전체 화면이다.
- 관리자도 물품 목록 카드를 누르면 공개 상세로 들어가고, 상세의 '수정' 버튼으로 수정
  화면에 간다. 수정 저장·취소는 그 상세로 돌아온다. (등록 저장은 새 물품 상세로)
- 관리자 전용 화면을 회원으로 열면 `/?role=denied`로 보내 홈에 권한 안내를 띄운다.
- 보호 화면은 세션 확인이 끝날 때까지 이전 화면(첫 진입은 로딩)을 유지한다.
